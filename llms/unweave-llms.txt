# Unweave

> Unweave ("Supabase for Machine Learning") is an open source platform for
> machine learning development environments: serverless GPU sessions, persistent
> volumes, SSH and VS Code access, and bring-your-own-cloud provider support,
> driven by a first-party CLI. Backed by Speedinvest. Development has been
> dormant since mid-2023 — the docs host (docs.unweave.io) and API host
> (api.unweave.io) are offline, while the website, blog, changelog, and pricing
> pages remain live.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21
(no provider-published /llms.txt was found on unweave.io or docs.unweave.io).

## Notes for agents

- There is no published OpenAPI/AsyncAPI specification; the REST API is an
  undocumented Go (chi) server whose source lives in unweave-v1/api.
- The hosted API (api.unweave.io) currently returns HTTP 525 and the app
  (app.unweave.io) returns 404 — treat the hosted platform as unavailable.
